# O que me interessa

> Exemplo. Reescreva com os seus critérios: é o que os agentes usam para separar o útil do resto.

**Quero ver**

- Jeitos práticos de usar IA no trabalho de quem cria conteúdo sozinho.
- Ferramentas novas que rodam no próprio computador.
- Formatos de vídeo que estão funcionando em canais pequenos.

**Não quero ver**

- Notícia de investimento, valuation, briga entre empresas.
- "X dicas" genéricas sem exemplo.
- Qualquer coisa que seja só reação a outro vídeo.
