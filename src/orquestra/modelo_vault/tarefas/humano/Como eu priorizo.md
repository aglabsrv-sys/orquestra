# Como eu priorizo

> Exemplo. Reescreva com as suas regras: os agentes leem isto antes de mexer nas suas tarefas.

- Gravação e edição vêm antes de qualquer tarefa administrativa.
- Não marco mais de três tarefas de prioridade alta no mesmo dia.
- Sexta é dia de newsletter: nada de gravação marcada para sexta.
- Se uma tarefa passar de três dias atrasada, quero ser perguntado se ainda faz sentido.
- Agentes podem criar tarefas para mim, mas nunca marcar uma tarefa minha como feita sem eu confirmar.
